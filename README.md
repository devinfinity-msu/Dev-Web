## 📌 Overview

**Dev Infinity** is the official student-driven Web Development Club under the **Department of Computer Science & Engineering, Faculty of Technology and Engineering (FTE), The Maharaja Sayajirao University of Baroda**.

We empower students through hands-on workshops, hackathons, open-source projects, peer collaboration, and real-world software engineering practice.

---

## 🚀 Key Features & Pages

- 🏠 **Home Page**: Hero section, quick club stats, institutional affiliation, *"What We Build"* specializations, and activity feed highlights.
- 📅 **Events & Workshops**: Live session streams with attendee counters, upcoming hackathons & workshops, past event recaps, and category filters.
- 💡 **Student Project Showcase**: Community web app portfolio, tech stack tags, GitHub repositories, live demo links, and project submission modal.
- ✍️ **Technical Blog**: Engineering insights, architecture tutorials, search bar, and category filters.
- 📚 **Learning Hub**: Roadmaps, workshop slide decks, clean code cheatsheets, and developer tools.
- 🏆 **Achievements**: State & national hackathon wins, open-source accomplishments, and institutional milestones.
- 👥 **Team Roster**: Faculty Coordinator, Core Team Leads, and Web Engineering Team roster.
- 📬 **Contact Us**: Institutional contact information, location at FTE Kalabhavan, and responsive enquiry form.
- 🛡️ **Admin Panel (`/admin`)**: Frontend control center layout featuring dashboard metrics, CRUD placeholders for events/projects/blogs, contact inbox, and **Certificate Generation Engine** with verification preview.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, React Router DOM v6, Lucide Icons, Pure Vanilla CSS (CSS Variables, Flexbox/Grid, Glassmorphism).
- **Future Backend**: Node.js + Express.js REST API.
- **Future Database**: Supabase (PostgreSQL).

## 💻 Getting Started (Local Setup)

1. **Clone the repository**:
   ```bash
   git clone https://github.com/devinfinity-msu/Dev-Web.git
   cd Dev-Web/frontend
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
